Made with SDL2 as a university project

build with:
linux: make  - (for some very strange reason I had libraries downloaded only, so you'll have to do it too, or run windows build with wine)
windows: make windows

All interactions are with the left mouse button, right mouse button to cancel tower placements

If you get bored of the provided game map or enemy waves, you can go to "Maps" folder and 
read "mapGuide.txt" to make your own!
