map file text is divided into 3 sections:
    -grid size (example 15x4 or just 15 if x and y are equal) 
    -enemy path (first line is number of points (remember than 5 points == 4 turns, first is an origin), rest is defined as an x and y point) 
    -grid textures (indices to an array of textures, each index == index.png in the assets folder (-1 is exclusive to path textures)) 

each section is ended by a line consisting of only a #
follow the syntax precisely (please)
game will only read "map.data" file, replace the current one with yours
put 0s, in the first collumn, UI will be placed over it, keep it in mind while building your level


// are used as comments, comments themselves will crash the game

3 // normally 15x4 or 20x4, 3 == 3x3 just as 10 == 10x10 
#
5 
0,0 //paths don't go diagonally
2,0 
2,2
1,2
1,1
#
0,0,0 //each line == all collumns (equal to x from section 1), amount of lines == all rows (equal to y from section 1)
